## 🏠 PropFlow — Autonomous Property Orchestration Engine  
🔗 https://github.com/Ankitkumar72/Gatex  

### 🧩 Problem  
Property maintenance workflows are fragmented and require manual coordination between tenants, managers, and technicians.

### 💡 Solution  
Developed a **multi-agent autonomous system** that can triage, decide, and execute maintenance workflows with minimal human intervention.

### 🏗️ System Architecture  
- **Triage Agent** → Classifies issue severity  
- **Knowledge Agent** → Retrieves contextual repair strategies  
- **Execution Agent** → Assigns and manages technicians  
- **Human Oversight Layer** → “Dead Man’s Switch” for financial approvals  

### ⚙️ Engineering Highlights  
- Built **stateful workflows using LangGraph**
- Designed **agent-to-agent communication pipeline**
- Implemented **decision-based routing system**
- Added **fail-safe approval mechanism for sensitive actions**

### 🛠️ Tech Stack  
Python · LangGraph · Gemini 1.5 Pro  

### 📈 Impact  
- Reduces operational overhead  
- Demonstrates real-world **AI orchestration system design**  
- Extensible for enterprise-level workflows
