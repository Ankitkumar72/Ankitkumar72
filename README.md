### Featured Projects

#### PropFlow — Autonomous Property Orchestration Engine

  * **Concept:** A multi-agent autonomous system designed to triage and execute property maintenance workflows.
  * **Architecture:** Built using LangGraph to manage stateful workflows between specialized agents (Triage, Knowledge, and Execution).
  * **Key Features:** Implemented a decision-based routing system and a human-in-the-loop "dead man’s switch" for financial approvals.
  * **Stack:** Python, LangGraph, Gemini 1.5 Pro.

#### Synq — Offline-First Productivity Platform

  * **Concept:** A modular productivity suite focused on data consistency across unstable network conditions.
  * **Architecture:** Feature-first modular design using Riverpod for state management and a custom FirebaseSyncCoordinator for conflict resolution.
  * **Key Features:** Background sync scheduling, local-first storage (Hive/SQLite), and multi-device stream synchronization.
  * **Stack:** Flutter, Dart, Riverpod, Firebase, Hive, SQLite.

#### Pixy — Performance-Optimized Music Player

  * **Concept:** A lightweight local music player focused on instant indexing and low resource consumption.
  * **Architecture:** Local-first caching layer using Hive to bypass standard file system latency.
  * **Key Features:** Custom Material 3 theming engine and audio focus lifecycle management.
  * **Stack:** Flutter, Dart, Hive.

#### AI Song Builder — Real-Time Collaborative Platform

  * **Concept:** A distributed system for multi-user collaborative AI music generation.
  * **Architecture:** WebSocket-based synchronization using Socket.io and an event-driven Node.js backend.
  * **Key Features:** Low-latency voting mechanism and synchronized playback across distributed clients.
  * **Stack:** Node.js, Socket.io, AWS.
